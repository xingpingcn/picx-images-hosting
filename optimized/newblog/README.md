# NewBlog responsive images

These pre-generated WebP files are served directly from cdn.jsdmirror.com.
The blog deployment does not proxy or serve their bytes.

Cover filenames retain the original PicX content hash and include the actual
output width. Cover variants use quality 78; the avatar uses quality 80.

The `logo/5beaa005-*` files come from the NewBlog site logo and use quality 82.
